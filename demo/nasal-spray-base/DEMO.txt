Scale note
- Source STL height was ~1.90 units; scaled to 48 mm for a believable sleeve size.
- Diameter ~14 mm after scale. Adjust scale if you want a different physical size.

The editable feature tree (now worth showing)
- CAD-View builds six hypotheses (extrude and revolve about each principal
  axis), scores volume, local surface residual, and normal agreement, then
  executes a parameter search on the winner.
- For this part it picks a native Revolve about the long axis:

      revolve   axis 2   IoU 0.906   <- selected after radius/profile refinement
      prismatic axis 2   IoU 0.698
      prismatic axis 0   IoU 0.662   <- what the old fixed heuristic used
      prismatic axis 1   IoU 0.554
      revolve   axis 0   IoU 0.208
      revolve   axis 1   IoU 0.185

- Old result: one extrude, 47.6% volume error.
  New result: one revolve, 1.8% volume error, 13-point profile sketch.
- The robust radius search avoids smearing the asymmetric lip around the whole
  body. The remaining mismatch is reported as localized residual regions;
  candidate extra features are rejected when they do not improve the executed
  solid enough to justify a more complex tree.
- Run parametric-revolve.vbs on a machine with SolidWorks to get a real
  feature tree (Sketch + Revolve1) you can edit, not an imported dumb body.
